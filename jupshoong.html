유튜브를 mp4로, 슈우웅

유튜브 URL만 붙여넣으면 원하는 화질로 바로 다운로드. 캡슝과 같은 감성의 가벼운 맥 앱이에요. 별도 설정 없이, 실행하면 다운로드 화면이 열립니다.

↓ 줍숑 다운로드 (.dmg) v1.0 · Apple Silicon 전용 · 릴리스 보기
기능

이렇게 동작해요

붙여넣고, 고르고, 받으면 끝. 세 단계로 유튜브 영상을 내 맥에 저장합니다.

🔗

URL 붙여넣기

유튜브 링크를 붙여넣고 “정보 가져오기”만 누르면 제목·길이·화질이 뜹니다.

🎚️

화질 선택

최고 화질(자동)부터 4K·1080p·720p까지, 원하는 화질을 골라 받습니다.

🎬

mp4로 저장

H.264 mp4로 변환해 어디서나 재생. ffmpeg가 앱에 내장되어 별도 설치가 필요 없어요.

🖥️

브라우저 화면

실행하면 브라우저에 깔끔한 다운로드 화면이 열립니다. 진행률도 실시간으로.

설치

드래그 한 번이면 끝

  1. 받은 .dmg를 열고 줍숑 을 Applications 로 드래그

    창 안의 화살표(Drag)를 따라 오른쪽 Applications 폴더로 옮기면 설치됩니다.

  2. 첫 실행 시 “확인되지 않은 개발자” 경고 → 여전히 열기

    시스템 설정 → 개인정보 보호 및 보안 → 아래로 스크롤해 “여전히 열기”. 이후로는 바로 열립니다.

  3. 실행하면 브라우저에 다운로드 화면이 열립니다

    유튜브 URL을 붙여넣고 화질을 골라 받으세요. 받은 영상은 다운로드 폴더에 저장됩니다.

Apple 개발자 공증이 없는 무료 배포판이라 첫 실행 경고가 한 번 뜹니다. 위 “여전히 열기”를 한 번만 해주면 됩니다.
